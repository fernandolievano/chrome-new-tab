## [1.0.0] - 2025-07-09

### Añadido

- Panel principal que muestra:
  - Estado de conexión (online/offline)
  - Cantidad de pestañas abiertas
  - Reproductores activos (tabs con audio)
- Imagen de fondo configurable por el usuario (archivo local)
- Estilo visual limpio con transparencia y blur
- Build con Vite + React + Tailwind
- Manifest V3 para compatibilidad con Chrome/Edge
